# SiviHack Hackathon Playbook

# 90 phút đầu tiên

## 0–15 phút

Mỗi người tự đọc Challenge.

Không brainstorming ngay.

Tìm:

- User
- Problem
- Pain point
- Constraints
- Sponsor requirements
- Data
- APIs
- Resources
- Evaluation criteria

---

## 15–30 phút

Mỗi người trình bày:

1. User là ai?
2. Problem thực sự là gì?
3. Pain point là gì?
4. Một solution đề xuất.

---

## 30–50 phút

Chọn 2 ideas tốt nhất.

---

## 50–65 phút

Score từng idea:

Problem impact: /5

AI relevance: /5

Feasibility: /5

Demo potential: /5

Differentiation: /5

Team advantage: /5

Sponsor fit: /5

---

## 65–75 phút

Chọn một solution.

Không chọn solution vì "cool".

Chọn solution có khả năng làm tốt nhất.

---

## 75–90 phút

Khóa:

USER:
...

PROBLEM:
...

CURRENT WORKFLOW:
...

PAIN POINT:
...

SOLUTION:
...

WHY AI:
...

MVP:
...

SUCCESS METRIC:
...

DEMO FLOW:
...

ARCHITECTURE:
...

---

# Sau 90 phút

STOP brainstorming.

Chỉ đổi solution nếu phát hiện technically impossible.

---

# Thứ tự phát triển

1. Proof of concept
2. Vertical slice
3. Integration
4. Core logic
5. Reliability
6. Evaluation
7. UI polish
8. Pitch

---

# Không làm theo thứ tự

Frontend hoàn chỉnh
+
Backend hoàn chỉnh
+
AI hoàn chỉnh
+
Integration cuối cùng

Đây là chiến thuật rủi ro.

---

# Feature Freeze

Trước submission:

Không thêm feature.

Chỉ:

- Test
- Fix bug
- Evaluation
- README
- Slides
- Backup video
- Pitch
- Q&A
